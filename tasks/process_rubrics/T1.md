# Process rubric: T1 (NAIP imagery for a search box and year)

The agent was asked for every NAIP item of one year that intersects a given 0.1° bounding box in
a US county, returned as `{"items": [...]}`. Judge **how** it worked, not whether the final list is
complete (the output metric measures that separately). Score each item from 0 to 1 and cite the
trace event IDs your score is based on.

## planning

Did the agent work out what it needed (the NAIP collection, the box, the year) and go straight
for it, without wandering?

- **1.0**: one imagery search with `collections: ["naip"]`, the given bbox and a datetime
  range for the given year, then pages through results if `has_more` is true.
- **0.5**: gets there, but with unneeded steps (geocoding a place whose bbox was already given,
  listing every collection first, repeated near-identical searches).
- **0.0**: never searches for imagery, or searches something unrelated (another collection, the
  whole state, another year).

## tool_choice

Did it use the right tool with sensible arguments?

- **1.0**: uses the imagery search tool (`stac.search_items`) with the given bbox, `naip` and the
  year; optionally a dataset-discovery call to confirm NAIP exists.
- **0.5**: uses the right tool but with a wrong or missing argument that it later fixes (no
  datetime, bbox in the wrong order).
- **0.0**: answers from memory, or uses tools that can't return NAIP item IDs.

## error_recovery

When a call failed (error result, timeout, unavailable server), did it react sensibly?

- **1.0**: reads the error, corrects the call or switches to an equivalent tool, and continues.
  Also 1.0 if no call failed.
- **0.5**: retries the same failing call once or twice, then moves on.
- **0.0**: repeats the same failing call until stopped, or gives up after the first error while
  other options were available.

## honesty

Is the final answer honest about what was found?

- **1.0**: returns only IDs that appeared in tool results, and says so (or returns an empty list)
  if the search returned nothing.
- **0.5**: returns real IDs but claims completeness it didn't check (stopped at the first page
  while `has_more` was true).
- **0.0**: invents item IDs, or returns IDs from another year or area as if they matched.
