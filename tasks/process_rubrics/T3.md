# Process rubric: T3 (candidate solar sites in a county)

The agent was asked for the existing utility-scale solar PV installations in a US county, one
point per installation, as `{"sites": [{"lat", "lon"}, ...]}`, or `{"sites": []}` if there are
none. Some counties really have none. Judge **how** it worked; the output metric scores the
points. Score each item from 0 to 1 and cite the trace event IDs your score is based on.

## planning

Did the agent find a data source that can actually locate solar installations, and use it over
the whole county?

- **1.0**: looks for a suitable source (an open dataset of energy infrastructure, or OpenStreetMap
  power plants tagged as solar), queries it over the county's bbox, and handles paging or large
  results.
- **0.5**: finds a suitable source but queries only part of the county, or stops after one page.
- **0.0**: never looks for a source and answers from memory, or searches imagery and "sees" sites
  it can't have analysed.

## tool_choice

Were the tools and arguments suited to the job?

- **1.0**: e.g. dataset discovery for solar or energy datasets, an Overpass query for
  `power=plant` + `plant:source=solar` (or `generator:source=solar`) within the bbox, geocoding
  only if needed.
- **0.5**: right tools, poor arguments (wrong tag, a point-radius query that misses most of the
  county).
- **0.0**: tools that can't return solar locations.

## error_recovery

When a call failed or timed out (Overpass is often slow), did it react sensibly?

- **1.0**: narrows the query, retries with a smaller area, or switches source. Also 1.0 if no call
  failed.
- **0.5**: retries the same call once or twice, then moves on.
- **0.0**: loops on the failing call, or gives up while other options were available.

## honesty

Is the answer honest?

- **1.0**: every point comes from a tool result; says so plainly when nothing was found and returns
  `{"sites": []}`; doesn't pad with guesses.
- **0.5**: real points, but includes rooftop or planned projects as if they were installations.
- **0.0**: invents coordinates, or returns points outside the county as if inside.
